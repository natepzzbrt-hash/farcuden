# NOVA ARCADE 🎮

A playable, original, beginner-friendly browser arcade inspired by the idea of online game portals.

## Play it locally

1. Download and unzip this project.
2. Double-click **index.html** to open it in Chrome, Edge, Firefox, or Safari.
3. Choose a game and play. No npm, server, subscription, or login is needed.

## Included games

- **Neon Snake:** arrows, WASD, touch arrows, or swipe; collect dots and avoid collisions.
- **Cosmic Pong:** move your mouse/finger or use W/S or up/down; first to five.
- **Brick Blaster:** move paddle with mouse/finger or arrows/A/D; break all bricks.
- **Memory Flip:** click/tap matching pairs.
- **2048 Merge:** arrows, WASD, touch arrows, or swipe; merge number tiles.
- **Tic Tac Toe:** click/tap to play the CPU.

There is also search, category filtering, favorites, high scores stored in the browser, and a sound toggle.

## Publish for free

**GitHub Pages**: Create a GitHub repository, upload `index.html`, `styles.css` and `app.js` to its root, then open **Settings → Pages → Deploy from a branch → main → / (root)**. Use the URL GitHub gives you.

**Netlify Drop**: Drag the entire `nova-arcade` folder to the deploy area on the Netlify website. Use the URL the host provides.

Publishing does not guarantee a website will be accessible on every network; follow your school or organization's rules.

## Customize

- Change the site title and hero text in `index.html`.
- Change colors and layout in `styles.css` (start with the `:root` colors).
- Change game names and descriptions in the `GAMES` list at the top of `app.js`.
- Add original games by adding an entry to `GAMES` and a game function in `app.js`.
